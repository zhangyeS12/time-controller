# 备份与恢复

time-controller 支持手动备份、自动备份和数据库恢复。

## 备份目录

备份默认保存在：

```text
%LOCALAPPDATA%\time-controller\backups\
```

## 手动备份

用户可以在数据设置页点击“立即创建备份”，程序会复制当前数据库并生成一个带时间戳的备份文件。

## 自动备份

如果开启自动备份，程序会按照设置在合适的时机保存数据库副本。自动备份数量可以设置保留上限，避免备份文件无限增长。

## 恢复数据库

恢复数据库前，程序会尽量先备份当前数据库，然后再用选中的备份文件替换当前数据库。

恢复属于危险操作，建议在确认备份文件可靠后再执行。
