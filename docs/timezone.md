# 时间与时区

time-controller 支持设置统计使用时区，用来划分“今天”“最近 7 天”“本周”“本月”等时间范围。

## 为什么需要统计时区

如果系统时区和实际使用所在地不一致，直接使用系统时区可能会导致今天、周报或月报的边界不符合预期。

例如，你人在中国但电脑系统设置为英国时间，凌晨和晚上统计结果可能会被划到不同日期。

## 系统时区和统计时区

- 系统时区：Windows 当前使用的时区。
- 统计时区：time-controller 用来计算统计日期范围的时区。

默认可以使用系统时区。如果你长期在固定地区使用，也可以手动选择统计时区。

## 中国 / 英国时区选择

- 中国标准时间：适合在中国使用，UTC+08:00。
- 英国时间：适合在英国使用，会受到夏令时影响。

选择合适的统计时区后，今日统计、最近 7 天、本周、本月和报告分析会按该时区计算。
